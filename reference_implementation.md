## Reference Implementation

This page includes sample resources that can be leveraged to support the implementation of Digital Documentation of COVID-19 Certificates (DDCC). Content is for demonstration purposes only. 

Additional relevant resources are included in the [References](references.md), [Content Profiles](content_profiles.md), [Dependencies](dependencies.md).

### Reference applications

* **Certificate generation:** 
* [DDCC Transactions Mediator](https://github.com/WorldHealthOrganization/ddcc-transactions-mediator) for generating certificates
* [Open Smart Register Platform (OpenSRP) FHIR Core Demo application for vaccination certificates](https://www.fhircore.org/) - Background and video 
* [OpenSRP FHIR Core Smart Vaccination Certificates for Android](https://github.com/opensrp/fhircore/blob/main/docs/apps/smart-vax-certs.md) - Github description
* [OpenSRP Demo Application User Guide](https://github.com/opensrp/fhircore/blob/main/docs/covax-demo-app.md)
 
 
* **Certificate verification and validation:** 
* [Verifier Application](https://github.com/WorldHealthOrganization/who-verifier-app/) - QR code scanning app for Android
