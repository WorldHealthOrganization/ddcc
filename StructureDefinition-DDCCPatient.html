Resource Profile: DDCC Patient

Official URL: http://smart.who.int/ddcc/StructureDefinition/DDCCPatient Version: 1.0.0
Draft as of 2026-09-05 Computable Name: DDCCPatient

A DDCCPatient should:

  • if the [identifier.assigner](StructureDefinition-DDCCPatient-definitions.html#Patient.identifier] is set then the value of identifier.assigner should be set to reference the DDCC Organization resource associated to the PHA.
  • obeys who-ddcc-patient-1

Usages:

  • Use this Profile: DDCC Document, DDCC Provide Document Bundle and DDCC:VS Add Bundle
  • Refer to this Profile: DDCC Composition, DDCC Document Reference, DDCC DocumentReference return for QR, DDCC Folder... Show 3 more, DDCC Immunization, DDCC Immunization Recommendation and DDCC Submission Set
  • Examples for this Profile: Patient/DDCCPatientArabic, Patient/DDCCPatientChinese, Patient/DDCCPatientEnglish, Patient/DDCCPatientFrench... Show 2 more, Patient/DDCCPatientRussian and Patient/DDCCPatientSpanish
  • CapabilityStatements using this Profile: WHO DDCC Registry Service

You can also check for usages in the FHIR IG Statistics
