## Changes

 This provides a list of changes to the Digital Documentation of COVID-19 Certificates (DDCC) Implementation Guide (IG) since its initial release. 

 **2022-03-31 - v1.0.0** 

* Release with publication of DDCC: Test Result guidance.

 **2022-01-25 - v0.3.1** 

* Merge of draft DDCC: Test Result branch with DDCC: Vaccination Status content.

 **2021-08-27 - v0.3.0** 

* Public release of DDCC: Vaccination Status guidance.

 **2021-06-03 - v0.2.1** 

* Change from Smart Vaccination Certificate IG to DDCC IG.
* Updated based on feedback from public comment release and changed name to DDCC.

 **2021-03-04 - v0.0.1** 

* Initial version.
