## Security Privacy

Please see the published [Digital Documentation of COVID-19 Certificates (DDCC): Vaccination Status (DDCC:VS) ](https://www.who.int/publications/i/item/WHO-2019-nCoV-Digital_certificates-vaccination-2021.1) and the [Digital Documentation of COVID-19 Certificates (DDCC): Test Result (DDCC:TR)](https://www.who.int/publications/i/item/WHO-2019-nCoV-Digital_certificates_diagnostic_test_results-2022.1) Technical Specifications and Implementation Guidance for security and privacy considerations. In particular, see the following content: 
* minimum requirements for a DDCC,
* assumptions,
* ethical considerations and data protection principles,
* functional and non-functional requirements,
* national governance considerations, and
* implementation considerations.
 

Also see the [References](references.md) and mapped [functional requirements](functional_requirements.md), available within the implementation guide.
